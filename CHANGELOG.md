# Changelog

All notable changes to the Let's Enterprise Brand Kit will be documented in this file.

## [1.2.0] - September 2026

Reconciles the kit against **LE Design Canon v1.8.0** (locked 3 Aug 2026), which
supersedes this kit for values. Corrections only — the full token migration is
tracked separately.

### Fixed
- **The logo mapping was inverted.** `…Final-Logo_PNG.png` holds the *all-white*
  artwork and `…Final-Logo_LightMode.png` holds the *dark* artwork; the guide
  said the opposite for both, so following it put a white wordmark on a white
  page. Verified by pixel inspection, then renamed to
  `le-logo-white-on-dark.png` and `le-logo-dark-on-light.png` so filenames
  describe artwork and the trap cannot recur.
- **A forbidden colour pair was rendered in the guide's own example.** The §4.2
  button hovered from Enterprise Blue to Bright Teal while keeping white text —
  white on teal measures 2.33. Replaced with a darkened blue.
- **`Badge` paired every tone with its base colour rather than an ink variant.**
  Teal text on its own pale wash measures 2.14; emerald/amber/rose at `-400` on a
  `/10` wash are all under 3.0. Every tone now uses a canon ink variant.
- `Badge` was `flex`, not `inline-flex`, so it stretched to fill its container.
- `--font-highlight` fell back to `cursive`. Acoustica has no accented Latin, so
  a single diacritic swapped one script face for another mid-word and looked
  approximately intended. Falls back to Prompt now — visibly wrong when wrong.

### Changed
- **Retired three functional colours.** Emerald `#10b981` (green encodes no
  status; a settled state is neutral), rose `#f43f5e` (canon rejects it in
  favour of Ember `#B8421E`), amber `#f59e0b` (Marigold `#DDA22C`; `#f59e0b` is
  a reserved source hue). `Badge` keeps the old prop names as **deprecated
  aliases** mapping onto the canon replacement, so no call site breaks.
- `Badge` gains meaning-named `tone` values — `neutral`, `accent`, `link`,
  `act`, `danger`, `identifier` — replacing hue-named `color`.
- **§7 Brand Voice is now scoped to showcase.** It previously governed "any UI
  text… or autogenerated placeholder content", which put recruitment register on
  student surfaces. Keywords travel between contexts; register does not.

### Added
- `FONTS.md` — the licence record for all three families, which of them may be
  redistributed, and the warning that compliance is coupled to this repository
  staying **private**.
- Ink-pairing rule (§3.3) with measured ratios and both forbidden pairs named
  and not rendered.
- The three canon secondaries — Marigold, Ember, Ink Violet — and their ink
  variants (§3.2).
- Acoustica's 2.0× pairing rule and its three hard limits (§2.1, §2.2).
- Product vs showcase boundary (§4.5) — glass, gradient and motion are showcase
  treatments and do not belong on data.
- The register boundary and the Locus lead/recede rule (§7.1, §7.2).

### Known gaps — not in this release
- The 12 canon semantic tokens per theme, the derived ladder, the level ramp,
  the four state marks and the eight source colours are still absent.
- `globals.css` declares 3 colour variables against canon's 12 per theme.
- `SoftCard` and `AdminCard` still carry showcase treatment on product surfaces.
- Radii are 24/16px against canon's 12/8/4, and the ground is cool slate against
  canon's warm paper.
- No drift check: nothing fails when this kit and canon disagree.

## [1.1.0] - April 2026

### Added
- Local Font Files integrated into `assets/fonts/` (including the full sets for `Prompt`, `Supreme`, and `Acoustica`).
- `@font-face` links dynamically established in `globals.css` for absolute font fidelity.
- Background motif / graphic variations from the master PDF added to `assets/extracted_graphics/`.
- Sleek / Smart UI Guidelines added to `BRANDING_GUIDE.md` to introduce Glassmorphism, deep dark modes, and transition-based micro-interactions.

### Changed
- Replaced the default `slate` dark mode background in `AdminCard` with the official master `Deep Blue` (`#160E44`).
- Updated `SoftCard` with a frosted glass backdrop blur and increased breathing padding.
- Upgraded the `Badge` component to natively support `enterpriseBlue`, `deepBlue`, and `brightTeal` alongside standard functional colors.
- Formalized `globals.css` to rely heavily on root CSS variables (`--color-enterprise-blue`, `--font-headline`, etc.) instead of hardcoded strings.

## [1.0.0] - Initial Release

### Added
- Base `BRANDING_GUIDE.md` outlining the fundamental Let's Enterprise identity, typography scales (Tailwind), and color distributions.
- Creation of standard library components (SoftCard, AdminCard, Badge).
- `assets/` directory seeded with high-resolution Light and Dark mode logos.
- `globals.css` created for foundational styles and print optimization.
